# API Documentation Portfolio 📚

A structured API documentation portfolio built with **MkDocs Material**, showcasing REST API documentation skills.

🌐 **Live site:** https://vishal160703.github.io/api-documentation-portfolio/

---

## What's Documented

- **Posts API** — GET and POST endpoints with full request/response examples
- **Users API** — User creation endpoint
- **Authentication Guide** — Bearer Token auth explained
- **Use Case Workflow** — End-to-end chained API calls

---

## Tech Stack

| Tool | Purpose |
|---|---|
| MkDocs Material | Documentation site generator |
| Markdown | Content authoring |
| GitHub Actions | Auto-deploy on push |
| GitHub Pages | Hosting |
| Postman | API testing & validation |

---

## Run Locally

```bash
pip install mkdocs-material
mkdocs serve
```

Then open `http://127.0.0.1:8000` in your browser.
