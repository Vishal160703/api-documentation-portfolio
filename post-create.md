# POST /posts

Creates a new post on the server. Accepts post details in the request body and returns the created post including the server-generated ID.

---

## Endpoint

```
POST https://jsonplaceholder.typicode.com/posts
```

---

## Request Headers

| Header | Value | Required |
|---|---|---|
| `Content-Type` | `application/json` | Yes |
| `Authorization` | `Bearer YOUR_API_TOKEN` | Yes |

---

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `title` | string | Yes | Title of the post |
| `body` | string | Yes | Full content of the post |
| `userId` | integer | Yes | ID of the user creating the post |

---

## Example Request

```bash
curl -X POST https://jsonplaceholder.typicode.com/posts \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -d '{
    "title": "My First Post",
    "body": "This is the content of my post.",
    "userId": 1
  }'
```

---

## Example Response

```json
{
  "title": "My First Post",
  "body": "This is the content of my post.",
  "userId": 1,
  "id": 101
}
```

!!! note
    The `id` field is generated by the server and returned in the response. You do not pass it in the request.

---

## Response Fields

| Field | Type | Description |
|---|---|---|
| `title` | string | Title of the created post |
| `body` | string | Content of the created post |
| `userId` | integer | ID of the user who created the post |
| `id` | integer | Server-generated unique ID for the new post |

---

## Status Codes

| Code | Meaning |
|---|---|
| `201 Created` | Post successfully created |
| `400 Bad Request` | Missing or invalid request body fields |
| `401 Unauthorized` | Invalid or missing token |
| `500 Internal Server Error` | Server-side error |
